# 💻 Ankit's Personal Desktop

### More than a portfolio. A love story between a curious kid and a computer.

> Before I learned to write code, I fell in love with the world it could create.

Welcome to my digital world — a personal desktop where childhood curiosity meets creativity, code, games, and imagination.

I have always been fascinated by computers. Even as a kid, they seemed magical to me. I wondered how a screen could hold entire worlds, how games came alive through a few clicks, and how something built from circuits and code could inspire so much imagination.

Back then, I didn't understand programming. I simply admired the machine and the endless possibilities behind its screen.

**That admiration became curiosity. Curiosity became a passion. And that passion became my journey into development.**

This portfolio is my tribute to that first love.

Instead of presenting my work through a conventional website, I decided to build a computer-inspired experience — a place where visitors can explore my projects as if they were discovering a personal desktop.

Every icon is an invitation. Every window is a little discovery. Every interaction reflects the excitement I felt when I first started exploring computers.

Welcome to my world. Feel free to click around.

## 🚀 Getting Started

Want to explore the project on your own computer? Follow these steps.

### Prerequisites

Install the following before getting started:

- [Node.js](https://nodejs.org/) — Use a version compatible with the project's `.nvmrc` file.
- npm — Included with the standard Node.js installation.
- [Git](https://git-scm.com/) — To clone the repository.

Check your installations:

```bash
node --version
npm --version
git --version
```

### 1. Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/prakashankit1212-art/personal_portfolio-.git
```

### 2. Open the project folder

```bash
cd personal_portfolio-
```

### 3. Install dependencies

```bash
npm install
```

This installs the packages required to run and develop the project.

### 4. Start the development server

```bash
npm run dev
```

Vite will display a local URL in your terminal, usually:

```text
http://localhost:5173/
```

Open that URL in your browser to explore the portfolio.

### 5. Create a production build

When you're ready to build the project for production, run:

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

Vite will provide a local URL where you can preview the production build.
